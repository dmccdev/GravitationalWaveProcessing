# Gravitational Wave Signal Processing

This project is currently unfinished and is still in development

## About

A Python project for processing and analysing gravitational wave detector data from publicly available LIGO experimental data.
The goal is to build a "pipeline" that can process detector data and use signal processing and statistical methods to identify gravitational wave signals while removing signal noise.

## Current Progress

- Downloading and Saving LIGO strain data versus time
- Fourier transforms to view frequency of strain data
- PSD (Power spectral density) calculation
- Signal whitening
- Bandpass filtering
- Matched filtering (Working on currently)

## Technology being used so far

- Python
- NumPy
- SciPy
- Matplotlib
- HDF5

## Project Status

Currently, implementing matched filtering and signal to noise ratio analysis, with further features in the future.
Additionally, plans to add user interface for presenting data.
